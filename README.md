### 🛠️ Мой технологический стек:

* **Язык программирования:** Java 23 (Core, Collections, ООП, SOLID, DRY)
* **UI Автоматизация:** Playwright Java (Browser Context, Download API, высокоскоростной современный движок)
* **API Тестирование:** REST Assured (маппинг в POJO-модели через Jackson, контрактное тестирование)
* **Инфраструктура & Middleware:** Apache Kafka (KRaft-режим, асинхронные события), PostgreSQL (JDBI3 Core), WireMock Server (виртуализация сервисов и статические mappings)
* **Тестовые движки & Сборщики:** JUnit 5 (многопоточный параллельный запуск, Data-Driven сценарии через Net Datafaker), Maven
* **CI/CD & Безопасность:** GitHub Actions (параллельные Docker-сервисы с health-checks), GitHub Secrets, Dependabot, Git
* **Отчетность:** Allure Report (детальные шаги, графики, автоприкрепление PDF-артефактов, деплой на GitHub Pages)

### 🚀 Мой главный демонстрационный проект:
👉 **[aqa_framework](https://github.com/ExitArt/aqa_framework/tree/main)** — Высокотехнологичная многоуровневый Full-Stack экосистема автоматизации (UI + REST API + Kafka + PostgreSQL + WireMock) для [SauceDemo].
*   **Архитектура:** Жестко разделенная независимая структура (Decoupled Architecture: POM, Steps, DTO/Models, Инфраструктурные Utils).
*   **Сквозные E2E сценарии:** Полный бизнес-процесс от UI-действий с перехватом инвойсов через Playwright до верификации транзакций в PostgreSQL и валидации асинхронных JSON-событий в топиках брокера Apache Kafka.
*   **Изоляция & Стабильность:** Динамическое управление заглушками в Docker-контейнере WireMock и параллельный Data-Driven запуск тестов на основе внешних JSON-файлов.
*   **CI/CD оркестрация:** Полный цикл сборки в GitHub Actions с параллельным развертыванием зависимых сервисов и автоматической сборкой истории отчетов Allure.
